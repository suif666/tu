视频编码

越新的编码压缩率越高，但老显卡往往没有对应的硬件解码器 —— 那就只能纯 CPU 软解， 1080p60 会扛不住。选一个你机器**能硬解**的格式。
先点下面的「检测本机解码能力」，看哪一行的硬解是 ✅，再回来选。 选错会直接导致播放卡顿。

检测本机解码能力

这里的检测结果是浏览器原生能力（不受本扩展拦截影响）。 「硬解」= 有专用解码器，CPU 几乎不耗；「软解」= 全靠 CPU 算。

动效与滚动削减

关掉这些能明显降低 CPU / GPU 负载，代价是页面看起来「朴素」一些。
CSS 那一层（动画/过渡、毛玻璃、固定背景、平滑滚动）没有开关 —— 它是随扩展一起注入的静态样式表，运行时改不了。想关掉就编辑 reduce.css，删掉对应的那一段，然后到 edge://extensions 点一下「重新加载」。每段都有注释标明作用。
